## Deploy on Render

1. Upload **all files in this folder** to a GitHub repo (root must contain `package.json` + `server.js`).
2. Render → New → **Web Service** → connect repo.
3. Settings:

| Field | Value |
|-------|--------|
| Language | **Node** |
| Build Command | `npm install` |
| Start Command | `npm start` |

4. Open the Render URL.

## Local run

```bash
npm install
npm start
```
